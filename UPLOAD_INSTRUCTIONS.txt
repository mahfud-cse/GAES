GAES v0.22.1 - Netlify Functions Hotfix

1. Buka repository GitHub yang terhubung ke Netlify.
2. Upload folder "netlify" dari paket ini ke root repository.
3. Saat diminta, izinkan semua 9 file lama di netlify/functions diganti.
4. Commit satu kali.
5. Tunggu automatic deploy Netlify selesai.

Tidak perlu:
- mengubah atau menghapus environment variables;
- memasukkan ulang Firebase private key;
- mengubah netlify.toml;
- clear cache sebelum deploy.
